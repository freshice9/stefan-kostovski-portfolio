# Stefan Kostovski — Professional Portfolio

A complete responsive Next.js portfolio for Stefan Kostovski, featuring a professional monochrome portrait, charcoal/navy design, interactive project filters, about, skills, experience and direct contact links.

## Run locally

1. Install Node.js 20.9+ (LTS recommended).
2. Open a terminal in this folder.
3. Run `npm install` and then `npm run dev`.
4. Open http://localhost:3000.

## Deploy to Vercel

1. Upload this folder to a GitHub repository (do not upload `node_modules`).
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the default Next.js framework settings and click **Deploy**.
4. Vercel gives you a `.vercel.app` URL. Add a custom domain later if desired.

## Personalize before sharing with recruiters

- Review descriptions of projects and skills for exact accuracy.
- Add verified GitHub/LinkedIn URLs when available (none are invented in this version).
- Add repository/case-study links when ready.
- Add a CV PDF to `public/` and a corresponding download button if desired.
- Contact information is **public** on the website, as requested.

## Security / privacy

This is a static portfolio without a backend, database, tracking scripts, or contact-form endpoint. Contact links use `mailto:` and `tel:`. No API secrets are needed. Do not commit credentials or `.env` files.
